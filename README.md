# On-Site IT Support & Hardware Deployment

Real-world client workstation refresh completed during my IT Support internship, covering Windows workstation deployment, hardware installation, printer configuration, network connectivity, peripheral setup, troubleshooting, and post-deployment validation.

> **Privacy Note:** Client-identifying information, credentials, IP addresses, serial numbers, and other sensitive details have been intentionally excluded from this public case study.

---

## Project Overview

As part of my IT Support internship, I worked alongside a senior technician during an on-site hardware refresh for a business client.

The objective was to replace and deploy workstation equipment, peripherals, and network hardware while ensuring users could continue accessing the applications, printers, and data required for day-to-day operations.

### Deployment Scope

- Prepare equipment and new computers for deployment
- Replace and configure Windows workstations and displays
- Install UPS units, printers, and business peripherals
- Assist with Ethernet connectivity and network switch replacement
- Install required Microsoft Office applications
- Configure local Windows user accounts
- Test workstation, printer, peripheral, and network functionality
- Perform final validation before handover

## Practical Troubleshooting

During the deployment, one ultrawide monitor was not displaying at its native resolution and would not fill the entire screen.

I checked Windows Display Settings and found that the expected ultrawide resolution was unavailable.

We then tested the physical display connection by replacing the existing DisplayPort cable with another cable.

After replacing the DisplayPort cable, Windows correctly detected the display and the monitor returned to its full native resolution.

<p align="center">
  <img src="images/display-troubleshooting.jpg" width="55%">
</p>

### Troubleshooting Summary

| Stage | Details |
|---|---|
| **Issue** | Ultrawide monitor not displaying at full resolution |
| **Investigation** | Checked Windows display settings, available resolutions, and display connection |
| **Root Cause** | Faulty/problematic DisplayPort cable |
| **Resolution** | Replaced the DisplayPort cable |
| **Result** | Monitor successfully displayed at full native resolution |
